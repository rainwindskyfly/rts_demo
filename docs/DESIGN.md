# rts_demo 策划案

> 代号 rts_demo · Godot 4.7.2-stable (GDScript) · Windows 桌面导出 .exe
> 定位：今晚一晚内完成、clone 后可直接跑起来的 RTS 微缩 demo（微缩 = 小而完整）
> 版本 v1.0 · 2026-10-29

---

## 1. 一句话定位

**用一个晚上做出一局 10~20 分钟、能真正打完的 1v1 RTS 垂直切片**，证明"框选 → 下令 → 自动战斗 → 采矿 → 造兵 → 推家"这条经典 RTS 核心链路，在 Godot 4.7 + 零外部素材（纯程序化几何美术）下代码量足够小、手感成立。

## 2. 目标玩家与体验目标

**目标玩家**：玩过星际争霸/红警但没做过游戏的人；以及需要一个可复现 RTS 原型的开发者。
**不面向**：APM 高手、竞技玩家（单机热座 1v1，无网络对战）。

玩家在 **前 3 分钟** 内应该理解：

| 时间 | 玩家应该理解的事 | 可观察行为 |
|---|---|---|
| 0:00–0:30 | 右上角小地图 = 全局战场，底部 = 我的基地 | 玩家主动去看小地图 |
| 0:30–1:00 | 左键框选、右键下令；单位会自动索敌开火 | 玩家对敌方单位下过一次右键 |
| 1:00–2:00 | 资源是造兵的唯一来源；工兵采矿、矿石要运回基地/采矿站 | 玩家先造采矿站/兵营而不是先造坦克 |
| 2:00–3:00 | 敌方 AI 会扩张并进攻，必须抢中央矿 | 玩家主动向地图中央移动 |

**体验目标**：第 3 分钟时玩家能自己说出"我先攒步兵，再一起推过去"。
**反体验目标**：不做滚屏刷兵、不做微操拼操作、不做倒计时压力之外的复杂度。

## 3. 核心玩法循环

选中单位 → 右键下达命令（移动 / 攻击 / 采集）→ 单位沿导航网格自动寻路并在射程内自动开火 → 击杀与采集同时抬高资源存量 → 用资源在兵营/基地里造出更多单位 → 单位数量与科技（本期只有两条兵种线）决定战场优势 → 集中兵力摧毁敌方基地（HQ）获胜，中途资源见底、兵源断档则被推家。循环周期：一次进攻决策 ≈ 60~90 秒，完整一局 ≈ 10~20 分钟。

## 4. 系统设计

### 4.1 相机

| 项 | 数值 |
|---|---|
| 视口 | 固定 1280×720 窗口（本期不做分辨率自适应） |
| 地图尺寸 | 2400×1350 px 世界坐标 |
| 默认缩放 | 1.0（此时可见 1280×720 区域，约地图 53% 宽度） |
| 缩放范围 | 0.6 – 2.0，滚轮每格步进 0.2；0.6 时可见 2133×1200 ≈ 全图 |
| 平移方式 | 中键拖拽 / WASD，速度 700 px/s（按住 Shift 加速至 1400 px/s） |
| 边界 | 相机矩形始终限制在地图矩形内，不露出黑边 |
| 事件跳转 | Space = 定位到最近一次战斗；H = 回基地 |

> 实现映射：`scenes/camera_rig.tscn`、`scripts/camera_rig.gd`

### 4.2 单位

三种单位（2 种可战斗 + 1 种采集），双方阵营各一套，属性完全对称。

| 单位 | 血量 HP | 攻击力 | 攻击间隔 | 射程 (px) | 移动速度 (px/s) | 造价 (矿) | 生产时间 | 生产建筑 |
|---|---|---|---|---|---|---|---|---|
| 步兵 Infantry | 80 | 8 | 0.8 s | 26（近战） | 130 | 50 | 6 s | 兵营 |
| 坦克 Tank | 260 | 24 | 1.6 s | 220 | 70 | 150 | 14 s | 兵营 |
| 工兵 Worker | 45 | 4 | 1.2 s | 20（近战） | 100 | 40 | 5 s | 基地 HQ |

**伤害规则**（无随机浮动，结算确定性，便于验收）：

| 攻击方 \ 目标 | 步兵 | 坦克 | 工兵 | 建筑 |
|---|---|---|---|---|
| 步兵 | 8 | **4** | 8 | 8 |
| 坦克 | 24 | 24 | 24 | 24 |
| 工兵 | 4 | **1** | 4 | 4 |
| 建筑 | — | — | — | — |

加粗表示护甲减伤：坦克对步兵系减伤 50%，工兵对坦克几乎无威胁。

**平衡校验**（同造价 150 矿对撞）：

| 对局 | 结果 | 说明 |
|---|---|---|
| 1 坦克 vs 1 坦克 | 约 18 s 同归于尽 | 坦克正面强、但贵且慢 |
| 1 坦克 vs 3 步兵 | 坦克胜，损失约 2 个步兵 | 单个坦克能碾压步兵，但换算成本亏 |
| 2 坦克 vs 6 步兵 | 步兵略胜 | 数量压制是步兵的答案，符合预期分工 |
| 1 步兵 vs 1 步兵 | 约 8 s | 快速结算，不拖长对局 |

其它规则：坦克开火为弹丸（速度 320 px/s），有飞行时间；步兵/工兵为瞬时近战；单位死亡立即从场景移除并释放血条；工兵死亡时携带矿石全部损失（不做掉落）。

> 实现映射：`scenes/units/{infantry,tank,worker}.tscn`、`scripts/unit.gd`、`scripts/unit_stats.gd`、`scripts/combat.gd`

### 4.3 选择与编队

| 行为 | 规则 |
|---|---|
| 单击 | 选中点击位置最近的一个己方单位（搜索半径 24 px） |
| 框选 | 左键拖拽出矩形；只选己方单位；中心点落在框内 → 必选；与框相交面积 ≥ 30% → 选 |
| 框内数量 | HUD 显示 `n/框内总数`，例如 `3/3` |
| 双击单位 | 选中视口内所有同类型单位 |
| Ctrl+A | 选中所有可战斗单位 |
| 编队 | Ctrl+1..9：把当前选中单位**追加**到该编队；同组上限 20 个单位 |
| 调用 | 1..9：选中并命令该编队移动到当前鼠标位置；双击数字键 = 相机居中到该编队 |
| 取消 | 点击空地 / ESC 清除选择 |

**P2 优先级说明**：若今晚时间不足，**编队（4.3 的 Ctrl+N / N 两条）可降级为 P2**，先做框选 + 右键命令 + 单选。第 2 节的 3 分钟理解目标不依赖编队，因此降级不影响可玩性判定。

> 实现映射：`scripts/selection_manager.gd`、`scripts/control_group.gd`

### 4.4 战斗

| 项 | 规则 |
|---|---|
| 索敌 | 半径 = 射程 + 80 px 内最近的敌方单位；优先已锁定目标未死亡则不换目标 |
| 攻击 | 进入射程即自动开火，按攻击间隔结算；移动中也可开火（边走边打） |
| 受击反馈 | 单位被命中闪白 0.1 s |
| 血条 | 单位头顶 24×3 px 血条，满血绿、<50% 黄、<25% 红；仅在受伤或被选中时显示 |
| 死亡 | HP ≤ 0 → 播放 0.3 s 淡出 → 从场景树移除，释放占位 |
| 建筑 | 不可移动、不可攻击、不被自动索敌；被攻击时无反击 |

> 实现映射：`scripts/combat.gd`、`scenes/projectile.tscn`、`scripts/health_bar.gd`

### 4.5 寻路

| 项 | 规则 |
|---|---|
| 方案 | `NavigationRegion2D`（烘焙一次）+ 每单位 `NavigationAgent2D` |
| 障碍 | 4 丛不可通行区，由地图静态碰撞体生成导航网格 |
| 重算节流 | 每个单位最多 4 次/秒 请求路径；路径失效或目标移动 > 60 px 才重算 |
| 避让 | 单位间用半径 14 px 的软分离力避免完全重叠 |
| 兜底 | 寻路超时 2 s 未获得路径 → 直线朝目标 + 贴墙滑动；再失败则原地待命 |

> 实现映射：`scenes/map.tscn`（NavigationRegion2D）、`scripts/pathing.gd`

### 4.6 资源

| 项 | 数值 |
|---|---|
| 资源种类 | 矿石 Minerals（唯一） |
| 上限 | 999 |
| 起始资源 | 350（双方相同） |
| 矿脉储量 | 家矿 900 / 中立矿 800 / 中央矿 1200（挖空后消失并显示枯竭贴图块） |
| 工兵载重 | 5 矿石/趟 |
| 采集时间 | 2.0 s / 趟（每趟固定 5 矿） |
| 单工兵产出 | ≈ 0.75 矿/秒（家矿往返约 220 px） |
| 团队基准 | 4 工兵 ≈ 3.0 矿/秒 ≈ 180 矿/分钟 |
| 转化点 | 采矿站（首选）或基地 HQ，半径 70 px 内自动卸货，矿石立刻计入资源 |
| 工兵死亡 | 携带矿石全部损失，不掉落地面 |

> 实现映射：`scripts/resource_manager.gd`、`scripts/worker.gd`、`scenes/ore_field.tscn`

### 4.7 建筑

| 建筑 | 血量 HP | 造价 (矿) | 建造时间 | 功能 | 每方上限 |
|---|---|---|---|---|---|
| 基地 HQ | 1000 | 不可建造（起始建筑） | — | 生产工兵、接收矿石、被摧毁即失败 | 1 |
| 兵营 Barracks | 500 | 120 | 20 s | 生产步兵 / 坦克 | 3 |
| 采矿站 Refinery | 300 | 100 | 15 s | 工人卸货点，**必须建在矿脉上**（矿脉 60 px 内） | 5 |

补充：建造时立即扣除造价并进入建造进度条，HP 按进度 0→满线性增长（被打断则保留已建进度但造价不返还，简化）；生产队列：兵营 5、基地 3；同时存在单位上限 40/方；建筑被摧毁后单位生产立刻停摆。

> 实现映射：`scenes/buildings/{hq,barracks,refinery}.tscn`、`scripts/building.gd`、`scripts/build_manager.gd`

### 4.8 敌方 AI（单机热座，不做难度选择）

状态机，每 2.0 s 评估一次，优先级从高到低：

| 状态 | 进入条件 | 行为 |
|---|---|---|
| DEFEND 防守 | 敌方单位进入己方基地 500 px 半径内 | 全部战斗单位回防，暂停进攻 |
| MASS 集结 | 战斗单位 ≥ 6 且兵营已建成 | 部队移动到基地旁的集结点等待 |
| ATTACK 进攻 | 满足 MASS 且距上次进攻 ≥ 45 s | 全军移动-攻击敌方 HQ |
| PRODUCE 生产 | 常态 | 兵营队列常满；配比 1 坦克 : 3 步兵 |
| ECONOMY 经济 | 常态 | 工兵不足 4 个则优先补工兵；家矿采空则去中央矿或建第二个采矿站 |
| BUILD 建造 | 开局 90 s 未有兵营 / 需要新采矿站 | 造兵营或采矿站 |

AI 行为约束：AI 不会造第 4 个兵营；AI 工兵上限 5；AI 不使用编队功能。

> 实现映射：`scripts/ai/ai_controller.gd`（状态枚举 + 评估函数）

### 4.9 HUD

| 区域 | 位置 | 内容 |
|---|---|---|
| 资源条 | 左上 | `Minerals: 350 / 999`、`Income: 3.0/s`、`Units: 5/40` |
| 计时器 | 顶中 | `20:00` 倒计时，剩余 60 s 变红 |

| 建造面板 | 右下 | 5 个条目（兵营 120 / 采矿站 100 / 步兵 50 / 坦克 150 / 工兵 40），含快捷键、造价、排队进度 |
| 提示条 | 屏幕中下 | 开局 3 s 教学提示 + 建造错误提示（资源不足/不能建在这里） |

> 实现映射：`scenes/hud/hud.tscn`、`scripts/hud.gd`

### 4.10 胜负条件

| 规则 | 说明 |
|---|---|
| 胜利 | 摧毁敌方 HQ（HP 1000）→ 立即结束，胜利 |
| 失败 | 己方 HQ 被摧毁 |
| 超时 | 20:00 到达 → 计算战场权重：存活步兵×1 + 工兵×0.5 + 坦克×4 + 存活建筑×2，高者胜 |
| 平局 | 权重相同 → 比较累计采集矿石总量，仍相同则判平局 |
| 认输 | ESC → 菜单 → Surrender 立即判负 |

> 实现映射：`scripts/match_manager.gd`、`scripts/game_state.gd`

## 5. 操作方案

| 输入 | 行为 |

| 1..9 | 选中并命令编队 N 移动到鼠标位置 |
| 双击 1..9 | 相机居中到编队 N |
| Ctrl + A | 选中所有可战斗单位 |
| H | 相机回到基地 |

| B | 打开 / 关闭建造面板 |

## 6. 关卡与场景设计

**地图**：2400×1350 px 矩形平地，无地形高度（纯 2D），仅障碍区不可通行。整体关于中心 (1200, 675) **中心对称**，保证 1v1 公平。

| 元素 | 坐标 (px) | 说明 |
|---|---|---|
| 玩家 1 基地（蓝） | (180, 1180) | 左下角 |
| 玩家 2 基地（红） | (2220, 170) | 右上角 |
| 蓝方家矿 | (320, 1010) | 储量 900，紧邻蓝方基地 |
| 红方家矿 | (2080, 340) | 储量 900，紧邻红方基地 |
| 中央矿 | (1200, 675) | 储量 1200，双方必争 |
| 中立矿 A | (620, 300) | 储量 800 |
| 中立矿 B | (1780, 1050) | 储量 800 |
| 障碍 1 | (900, 980)，半径 130 | 蓝方到中央的必经侧翼 |
| 障碍 2 | (1500, 370)，半径 130 | 与障碍 1 对称 |
| 障碍 3 | (700, 520)，半径 95 | 左上通道 |
| 障碍 4 | (1700, 830)，半径 95 | 与障碍 3 对称 |

对称校验：(180,1180)→(2220,170) ✔；(320,1010)→(2080,340) ✔；(620,300)→(1780,1050) ✔；(900,980)→(1500,370) ✔；(700,520)→(1700,830) ✔。

**初始部署**（双方完全相同）：HQ ×1 + 工兵 ×2 + 步兵 ×1 位于基地旁；资源 350 矿。

> **实现说明**：开局工兵会被**自动指派**去家矿脉采矿，玩家不必先手动下达采集指令就能看到经济循环跑起来；玩家仍可随时右键重新指派。

**地图外区域**用深灰矩形覆盖，相机不可越界。

> 实现映射：`scenes/map.tscn`、`scripts/map_setup.gd`（坐标表直接作为常量写入此脚本）

## 7. 美术与 UI 方案

**原则：零外部素材依赖。** 仓库内不放任何 `.png/.jpg/.ogg/.ttf` 美术资源，全部由 Godot 原生节点程序化绘制。

| 对象 | 表现方式 |
|---|---|
| 地面 | 单个 `ColorRect`（深绿灰 `#3a4a3a`）+ 8×8 px 网格 `Line2D` |
| 单位 | `Polygon2D` 色块：步兵 10×10 白蓝、坦克 16×16 橄榄、工兵 8×8 橙；头顶加 4 px 朝向小三角表示面朝方向 |
| 建筑 | `ColorRect` 主体 + `Polygon2D` 屋顶：HQ 56×56、兵营 36×28、采矿站 24×24 |
| 矿脉 | 8–12 个随机大小/位置的深灰 `Polygon2D` 石块，储量越低块数越少 |
| 障碍 | 暗色 `Polygon2D` 不规则多边形 |
| 血条 | 单位头顶 `ColorRect` 24×3，按 HP 比例改色 |
| 选中框 | `Line2D` 黄色描边（2 px） |
| 血条 / 选中框绘制 | 由单位节点自身 `draw()` 负责，HUD 无关 |
| UI | `Control` + `ColorRect` 面板 + `Label` 文本，Godot 内置默认字体 |

**为什么这样能保证 clone 即可运行**：仓库里没有需要额外下载/授权/解压的资源，git clone 后直接用 Godot 打开 `project.godot` 即可运行，不会因为缺资源报红。

**文字语言约束**：Godot 内置默认字体不含中文字形，中文 HUD 会显示豆腐块。因此 **HUD 全部使用英文短词**（Minerals / Infantry / Tank / Worker / Barracks / Refinery / HQ / Units / Income），中文只出现在本策划案与 README。若后续要中文 UI，需额外打包 Noto Sans SC（OFL 授权）——本期不做。

## 8. 音频方案

**本期采用静音占位。**

| 项 | 方案 |
|---|---|
| BGM | 不做 |
| SFX | 不做（无任何音频文件、AudioServer 无输出） |
| 预留接口 | 在场景中预置 5 个 `AudioStreamPlayer` 通道（选中 / 命令 / 开火 / 建造 / 告警）与 `scripts/audio.gd` 的 5 个空函数调用点 |
| 升级路径（可选，最后 30 分钟才做） | 用 `AudioStreamGenerator` 程序化生成 0.1 s 方波/噪声当点击与开火音，无需外部文件 |

本期不做：音量设置菜单、混音、音效分层与优先级。

## 9. UI/UX 流程

1. **启动** → 主菜单：仅 `Start` / `Controls` / `Quit` 三个按钮（Controls 内嵌第 5 节按键表）。
2. **点击 Start** → 0.5 s 黑场过渡 → 进入地图，相机定位蓝方基地并给一次全屏视野拉远（1.5 s 演示镜头，展示中央矿与敌方方向）。
3. **开局 3 s**：屏幕中下弹出提示条 `Left-drag to select · Right-click to command · B to build`，3 s 后淡出。
4. **对局**：HUD 常驻；玩家采集、造兵、进攻；AI 防守/集结/进攻；发生战斗时屏幕边缘短暂红色告警闪烁。
5. **结束**：胜负大字（`VICTORY` / `DEFEAT` / `DRAW`）+ 用时 + 统计（采集总量 / 造兵数 / 击杀数）+ `Play Again`（回主菜单）。
6. **ESC 暂停**：Resume / Restart / Surrender / Quit to Menu，半透明遮罩。

## 12. 风险与备选方案

| # | 风险 | 概率 | 影响 | 触发点 / 备选降级方案 |
|---|---|---|---|---|
| 1 | Godot 4.7.2 导出模板下载慢或失败 | 中 | 高 | 先用编辑器 F5 验证全部功能，导出放到最后一小时；模板失败则先交付"编辑器可跑 + README 导出步骤" |
| 2 | 多单位 NavigationAgent2D 互相卡死/抖动 | 高 | 高 | 超过 20 分钟没跑顺 → 降级为"直线 + 简单贴墙滑行"，取消避让与路径重算节流 |
| 3 | 寻路开销量大导致掉帧 | 中 | 中 | 单位上限 40/方 → 降到 25/方；寻路请求节流到 4 Hz |
| 4 | 框选手感不好（选不中 / 误选） | 中 | 中 | 降级为"点击选最近 + 双击选同类"，取消拖拽框选 |
| 5 | 战斗节奏拖沓（对局打不完） | 中 | 中 | 伤害值上调一档（步兵 8→10）或超时缩到 15 分钟 |
| 6 | AI 表现笨拙 / 不进攻 | 中 | 中 | 降级为固定波次：每 60 s 从两个方向各送一波固定编队 |
| 7 | HUD 中文豆腐块 | 已规避 | — | 已规定 HUD 全英文；若要求中文 UI 需打包 Noto Sans SC（超出本期） |
| 8 | 场景/脚本数量过多导致收尾来不及 | 高 | 中 | 严格按第 10 节"本期做"清单砍：先砍编队（4.3 P2），再砍建造面板快捷键，最后砍小地图上的单位点 |
| 9 | 音频需求临时被追加 | 低 | 低 | 保持静音占位；如需则用 AudioStreamGenerator 生成 0.1 s 方波，限时 30 分钟 |
| 10 | 打包后 exe 启动即崩（缺 dll / 路径） | 低 | 高 | 提前 1 小时做一次干净导出并在无 Godot 环境下试跑 |

**时间切分建议**：0:00–1:00 地图 + 相机 + 地形 ｜ 1:00–2:00 单位与选择 ｜ 2:00–3:30 战斗与寻路 ｜ 3:30–5:00 资源与建筑 ｜ 5:00–6:30 AI ｜ 6:30–8:00 HUD 与胜负 ｜ 8:00–9:00 导出与 README ｜ 9:00 之后为缓冲。编队系统（P2）只在缓冲时间内做。
